# SWER Broken Conductor Map

Capstone project website: **Geospatial Situational Awareness for SWER Broken Conductor Detection**
Sabrina Tavares · Bachelor of Engineering (Honours), Electrical and Electronic · Victoria University

A dashboard that shows operators *where* a broken SWER powerline is likely to be, not just *that* it broke, to help reduce bushfire risk.

Pipeline: utility KML maps → Python parser → PostgreSQL on AWS → Grafana.

## Files

- `index.html`: the whole website (one page, no build step)
- `images/`: photos and dashboard screenshots
